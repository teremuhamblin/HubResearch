📘 Présentation

HubResearch v1.6 est un portail statique multi‑pages conçu pour centraliser :  
- les projets d’ingénierie du MantraLab,  
- les modules IA (diagnostics, interpretability, safety),  
- les outils cyber‑ops et OSINT,  
- les drafts techniques et documents de recherche,  
- les contributeurs réels et fictifs du lab.

Le site est rapide, modulaire, scalable, et entièrement déployé via GitHub Pages.

⚙️ Installation & Développement

📦 Installer les dépendances
```bash
pnpm install
```

🧪 Lancer le serveur de développement
```bash
pnpm dev
```

🏗️ Build de production
```bash
pnpm build
```

Les pages statiques peuvent être prévisualisées avec n’importe quel serveur HTTP.
